    หมุนล้อเมาส์ = ซูม (กด Shift ค้างไว้ = ซูมเฉพาะแนวระยะ) · ลากภาพ = เลื่อน · ดับเบิลคลิก = เต็มเส้น
    
    
    ชี้บนภาพเพื่อดูตำแหน่ง
    
    
    

    
    
      เทียบกับซอฟต์แวร์อ้างอิง (ViewPoint / GeoLitix) 
      
    ใช้ผลจากซอฟต์แวร์ลิขสิทธิ์เป็นคำตอบอ้างอิงเท่านั้น: แนบภาพหน้าจอหรือภาพที่ส่งออก นำเข้าตารางจุดที่มาร์กไว้ (CSV)
        หรือวาดกรอบบนภาพของเราตรงตำแหน่งที่ซอฟต์แวร์นั้นมาร์ก แล้วโปรแกรมจะจับคู่กับโซนของเราให้ ตัดสินเองได้ทุกแถว
    
      
    
        
        
        
        
        แม่แบบ CSV
        
        
        
        
        
      
    
      
    
      
    
      
    อ้างอิงตำแหน่งอ้างอิงโซนเราต่าง (ระยะ / ลึกบน)ผลจับคู่ผู้ตรวจตัดสินหมายเหตุ
    
        
    
      
    
        เพิ่มจุดอ้างอิงด้วยตัวเลข
        
        
        
        
        
        
        
      
    
      
    
        ตรวจการอ่านไฟล์: ค่าที่ซอฟต์แวร์อ้างอิงแสดงสำหรับเส้นนี้

# ทดสอบ GPR Analyzer บน Windows ด้วยไฟล์จริง และเทียบผลกับ ViewPoint / GeoLitix

ไม่ต้องใช้ VS Code หรือพิมพ์คำสั่งใด ๆ

## 1. ติดตั้งครั้งแรก (ทำครั้งเดียว ประมาณ 5–15 นาที ต้องต่ออินเทอร์เน็ต)

1. ดาวน์โหลดโปรแกรมเป็นไฟล์ ZIP จาก GitHub (ปุ่ม **Code → Download ZIP** ของสาขาที่ได้รับลิงก์)
2. คลิกขวาที่ไฟล์ ZIP → **Extract All…** ไปไว้ที่ใดก็ได้ เช่น `D:\GPR-Analyzer`
   (ต้องแตกไฟล์ก่อน ห้ามเปิดจากในไฟล์ ZIP โดยตรง)
3. ในโฟลเดอร์ที่แตกออกมา ดับเบิลคลิก **`START-GPR-ANALYZER.bat`**
   - ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด **More info → Run anyway**
     (เป็นเพราะไฟล์ดาวน์โหลดจากอินเทอร์เน็ตและไม่มีลายเซ็น)
   - ถ้าเครื่องยังไม่มี Python โปรแกรมจะติดตั้ง Python 3.12 ให้เอง (ไม่ต้องใช้สิทธิ์ admin)
     ถ้าติดตั้งเองไม่ได้ จะเปิดหน้าเว็บ python.org ให้ ติดตั้งแล้วติ๊ก **Add python.exe to PATH**
     จากนั้นดับเบิลคลิกไฟล์ .bat อีกครั้ง
4. เมื่อเสร็จ เบราว์เซอร์จะเปิดหน้า GPR Analyzer เอง และมีทางลัด **GPR Analyzer** บนเดสก์ท็อป

ครั้งต่อไปดับเบิลคลิกทางลัดบนเดสก์ท็อปได้เลย เปิดภายในไม่กี่วินาที

**สำคัญ:** หน้าต่างสีดำต้องเปิดไว้ตลอดที่ใช้งาน ปิดหน้าต่างนี้ = ปิดโปรแกรม

- งานทั้งหมดเก็บไว้ที่ `เอกสาร (Documents)\GPR-Analyzer-jobs` ข้อมูลไม่ถูกส่งออกนอกเครื่อง
- อัปเดตเวอร์ชันใหม่: ดาวน์โหลด ZIP ใหม่ แตกทับโฟลเดอร์เดิม แล้วเปิดตามปกติ โปรแกรมจะติดตั้งส่วนที่เปลี่ยนให้เอง
  งานเก่ายังอยู่ครบ
- ถ้าเกิดปัญหาแปลก ๆ หลังอัปเดต: เปิด Command Prompt ในโฟลเดอร์โปรแกรมแล้วพิมพ์
  `START-GPR-ANALYZER.bat -Reinstall` หรือลบโฟลเดอร์ `%LOCALAPPDATA%\GPR-Analyzer` แล้วเปิดใหม่

## 2. ทดสอบไฟล์จริงทีละชุด

1. หน้าแรก: กด **📁 เลือกโฟลเดอร์…** แล้วเลือกโฟลเดอร์ข้อมูลของเครื่อง ImpulseRadar (หรือวางที่อยู่โฟลเดอร์แล้วกด
   **ตรวจโฟลเดอร์**) โปรแกรมจะอ่านจากโฟลเดอร์โดยตรง ไม่คัดลอกไฟล์
2. ตารางตรวจความครบถ้วนจะบอกทีละเส้นว่า ✓ ครบ / ⚠ ควรตรวจ / ✗ ใช้ไม่ได้ พร้อมเหตุผล (เช่น ไม่มีไฟล์ GPS, จำนวน trace
   ไม่ตรง header, GPS ขาดช่วง) และแผนที่แนวสแกนคร่าว ๆ ให้ดูตำแหน่ง
3. ติ๊กเลือกเส้นที่จะประมวลผล ถ้าสนใจเฉพาะช่วงสั้น ๆ ให้ใส่ช่วงระยะ (m) เช่น 120–150 แล้วกด **เริ่มประมวลผล**
   (ยังลากไฟล์มาวางแบบเดิมได้)
4. หน้าความคืบหน้าบอกว่าทำถึงเส้นไหน ขั้นตอนไหน และบันทึก `log.txt` ทยอยแสดง (เจอโซนอะไร ตรงไหนน่าสงสัย)
   กด **เปิดหน้าตรวจผล** ได้ตั้งแต่เส้นแรกเสร็จ เส้นที่เหลือจะทยอยขึ้นมาเอง
5. ถ้าไฟดับหรือเครื่องค้างกลางทาง: เปิดโปรแกรมใหม่ เลือกงานเดิมใน "งานก่อนหน้า" (จะขึ้นว่า **ค้าง ทำต่อได้**) แล้วกด
   **ทำต่อ** โปรแกรมจะทำเฉพาะเส้นที่ยังไม่เสร็จ เส้นที่เสร็จแล้วเปิดได้ทันทีโดยไม่ต้องประมวลผลใหม่
6. ถ้าไฟล์ใดอ่านไม่ได้ จะมีข้อความสีแดงด้านซ้าย จดชื่อไฟล์และข้อความไว้ส่งให้ผู้พัฒนา
7. หน้าตรวจทาน: ตรวจโซนที่โปรแกรมวงให้ (ยอมรับ / แก้ไข / ปฏิเสธ / วาดเพิ่ม) ตามปกติ

## 3. เทียบผลกับซอฟต์แวร์ลิขสิทธิ์ (ส่วน "เทียบกับซอฟต์แวร์อ้างอิง" ใต้ภาพเรดาร์)

เลือกซอฟต์แวร์อ้างอิงก่อน (ViewPoint หรือ GeoLitix) แล้วใส่ผลของซอฟต์แวร์นั้นสำหรับเส้นเดียวกัน
ทำได้ 4 แบบ ผสมกันได้:

| วิธี | ใช้เมื่อ |
|---|---|
| **แนบภาพ** | ถ่ายภาพหน้าจอ (Win + Shift + S) หรือภาพที่ซอฟต์แวร์นั้นส่งออก จะแสดงใต้ภาพของเราเพื่อดูเทียบด้วยตา |
| **นำเข้า CSV จุดที่มาร์ก** | ซอฟต์แวร์ส่งออกตารางจุด/โซนที่มาร์กได้ (เช่น annotation/picks ของ GeoLitix) โปรแกรมหาคอลัมน์ระยะและความลึกเอง ถ้าไม่เจอจะบอกชื่อคอลัมน์ที่พบ ดาวน์โหลด "แม่แบบ CSV" เพื่อกรอกเองใน Excel ได้ |
| **＋ วาดจุดอ้างอิง** | ซอฟต์แวร์ส่งออกตารางไม่ได้ ให้ลากกรอบบนภาพของเรา ตรงตำแหน่งที่ซอฟต์แวร์นั้นมาร์กไว้ |
| **เพิ่มด้วยตัวเลข** | อ่านระยะและความลึกจากหน้าจอซอฟต์แวร์นั้นแล้วพิมพ์ใส่ |

จากนั้นโปรแกรมจะจับคู่จุดอ้างอิงกับโซนของเราให้อัตโนมัติ แต่ละแถวจะเป็นหนึ่งใน

- **ตรงกัน**: ทั้งสองโปรแกรมเจอที่เดียวกัน (แสดงระยะและความลึกที่ต่างกัน)
- **เราไม่พบ**: ซอฟต์แวร์อ้างอิงเจอ แต่โปรแกรมเราไม่ได้วง
- **เราพบเกิน**: โปรแกรมเราวง แต่ซอฟต์แวร์อ้างอิงไม่ได้มาร์ก ให้ตัดสินว่า "น่าจะจริง" หรือ "ผิด"

ถ้าการจับคู่อัตโนมัติไม่ถูก เลือกโซนที่ถูกต้องเองในช่อง "อัตโนมัติ" ใต้แต่ละแถว และตัดสินในช่อง "ผู้ตรวจตัดสิน"
เกณฑ์ระยะห่างที่ถือว่าตรงกันปรับได้ในหัวข้อ "เกณฑ์จับคู่" (ค่าเริ่มต้น 1.0 m ตามแนวระยะ, 0.3 m ตามความลึก)

**ตรวจการอ่านไฟล์**: ในหัวข้อ "ตรวจการอ่านไฟล์" กรอกจำนวน trace, time window, ความยาวเส้น และความเร็วคลื่น
ที่ซอฟต์แวร์อ้างอิงแสดงสำหรับเส้นนี้ ถ้าขึ้น ✗ ไม่ตรง แปลว่าโปรแกรมเราอ่านไฟล์ผิด ต้องแจ้งผู้พัฒนา
ความเร็วคลื่นที่กรอกจะใช้แปลงความลึกของซอฟต์แวร์นั้นก่อนจับคู่ด้วย

**ให้คะแนนฟีเจอร์**: หัวข้อ "ให้คะแนนฟีเจอร์เทียบกับซอฟต์แวร์ลิขสิทธิ์" มีรายการตั้งต้นให้ เลือก ดีกว่า / พอ ๆ กัน /
แย่กว่า / ยังไม่มี และเพิ่มแถวเองได้ กด **บันทึกคะแนน**

## 4. ส่งผลให้ผู้พัฒนา

- ต่องาน: ปุ่ม **เทียบผล CSV** ด้านบนขวา (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
- ทุกงานรวมกัน: หน้าแรก หัวข้อ "งานก่อนหน้า" มีปุ่ม **รายเส้น CSV**, **รายจุด CSV**, **คะแนนฟีเจอร์ CSV**
- ส่งไฟล์ CSV เหล่านี้ พร้อม `labels.jsonl` และภาพหน้าจอที่น่าสนใจ ให้ผู้พัฒนา

ข้อตกลง: ใช้ ViewPoint และ GeoLitix เป็นคำตอบอ้างอิงจากสิ่งที่แสดงบนจอหรือส่งออกเท่านั้น
ไม่เปิดหรือแกะไฟล์โปรแกรมหรือระบบลิขสิทธิ์ของซอฟต์แวร์เหล่านั้น

## 5. ถ้าอยากให้ Claude ช่วยทดสอบบนเครื่องให้

ติดตั้ง Claude Code (แอปเดสก์ท็อปบน Windows) แล้วเชื่อมเครื่องเข้ากับโปรเจกต์นี้
Claude จะเปิดโปรแกรม ใส่ไฟล์จริงจากโฟลเดอร์ที่อนุญาต และรวบรวมผลให้ได้
ส่วนการเปิด ViewPoint / GeoLitix และส่งออกผลยังต้องทำโดยผู้ใช้ เพราะต้องใช้สิทธิ์ใช้งานของผู้ใช้เอง
